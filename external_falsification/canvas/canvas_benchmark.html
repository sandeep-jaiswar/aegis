About This Benchmark

This implementation uses HTML5 Canvas for direct 2D rendering to execute the APP-001 workload. Canvas adds overhead through:

  • Canvas API calls and state management
  • GPU rasterization and compositing
  • Browser rendering pipeline integration
  • Garbage collection from temporary objects
  • JavaScript event loop scheduling

Compare these results with the Aegis baseline to see the impact of browser rendering overhead on variance and predictability.
